Privacy

Privacy and account information

This page covers the Sword Client website and the standalone Sword Client launcher.

Website

The project website is a static page. It does not ask you to sign in or submit personal information, and it does not include analytics or advertising scripts. Links to Discord and GitHub open those services under their own privacy terms.

Microsoft sign-in in the launcher

If you use the standalone Sword Client launcher, sign-in opens Microsoft in your system browser. Sword Client does not ask you to send your Microsoft password to the project. Microsoft, Xbox, and Minecraft services process authentication and the account checks needed to launch Minecraft Java Edition.

Local launcher data

The standalone launcher stores account/session data and game files on your device in the Sword Client application folder under your Windows application data directory. Use the launcher's sign-out control to clear the saved account information. Deleting the local Sword Client folder also removes its local launcher and game data.

Original client package

The Minecraft client package runs through the launcher or installation method you choose. Account authentication is handled by that launcher; its data handling depends on that software.

Contact

For project questions, contact the maintainers through the GitHub repository or the Discord server.

Independent project: Sword Client is not affiliated with or endorsed by Mojang or Microsoft.
