Inside Sword Client

Make the interface yours.

The original client bundle includes a broad set of toggleable mods for combat information, visual settings, and everyday play.

01 / HUD

Useful match info

Keystrokes, CPS, coordinates, FPS, ping, armor status, potion status, and target information.

02 / VISUALS

Dial in your view

Custom crosshair, zoom, motion blur, hit color, item physics, animations, and visual controls.

03 / CONTROL

Toggleable mod menu

Browse categories, change settings, bind controls, and use the HUD editor to arrange your display.

04 / EXTRAS

More ways to play

Screenshot tools, cosmetics, server details, chat options, minimap, and quality-of-life displays.
